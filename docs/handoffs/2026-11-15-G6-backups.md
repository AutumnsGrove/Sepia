## What is needed from Autumn

Approval to install the units on the potato and run the drill, or to run it herself. The steps are in
`docs/INSTALL.md` section 4 ("The backup timer" and "The restore drill"). In short:

```bash
cd "$HOME/Sepia"
INSTALL_DIR="$HOME/Sepia"; USER_NAME="$(id -un)"
for f in compose/systemd/sepia-*.path compose/systemd/sepia-*.service compose/systemd/sepia-*.timer; do
  sed -e "s|@INSTALL_DIR@|$INSTALL_DIR|g" -e "s|@USER@|$USER_NAME|g" "$f" |
    sudo tee "/etc/systemd/system/$(basename "$f")" >/dev/null
done
sudo systemctl daemon-reload
sudo systemctl enable --now sepia-backup.timer sepia-backup.path

systemctl start sepia-backup.service          # one run now, without waiting for 03:30
journalctl -u sepia-backup.service -n 40 --no-pager
cat "$HOME/Sepia/data/backups/receipts.jsonl"
rclone lsf r2sepia:sepia-backups/db           # must name tonight's snapshot
```

Then the restore drill, into a scratch directory, never over `data/`:

```bash
mkdir -p /tmp/sepia-restore
docker compose exec sepia /sepia restore \
  --snapshot "/data/backups/db/sepia-$(date -u +%F).db" \
  --into /restore --compare /data/sepia.db
```

And the screen: Settings → Backups and export, on a phone, should show the last run, 4.x MB, "Mirrored", "Running",
and the run in Recent runs.

## What to watch for

- **The container is UTC and the board is America/New_York.** The timer fires at 03:30 board time; the receipt is
  stored in UTC and the screen formats it locally. Do not read the receipt's UTC hour as the run time.
- **The snapshot is a `.backup` output, not the live file.** `data/backups/db/sepia-YYYY-MM-DD.db` is the one to
  restore; `data/sepia.db` is live and is what `--compare` reads.
- **A failed receipt is not a lost review.** The local snapshot is written and checked before rclone runs. If R2
  fails, the screen says "Not copied" and the review is still on the board.
- **If `rclone lsf r2sepia:` 403s,** the token is the suspect, not the script. `rclone config show r2sepia` names the
  remote; the dashboard is the only place the key can be replaced.
